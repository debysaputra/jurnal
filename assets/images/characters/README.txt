Taruh gambar avatar karakter di folder ini.

Nama file HARUS sesuai id karakter (PNG, disarankan persegi, mis. 512x512,
latar transparan atau penuh):

  aira.png    -> Aira  (Kakak Penyemangat)
  naya.png    -> Naya  (Teman Tsundere)
  orion.png   -> Orion (Profesor)
  luna.png    -> Luna  (Pendengar Empatik)
  atlas.png   -> Atlas (Pelatih Produktivitas)

Setelah file ditaruh, jalankan ulang build. Avatar akan otomatis dipakai.
Jika file belum ada, aplikasi menampilkan emoji sebagai placeholder.

Catatan: gunakan hanya gambar yang Anda miliki haknya (mis. hasil generate
AI sendiri). Jangan memakai gambar berhak cipta milik orang lain.
